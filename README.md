# MediCrew

Medical transport staffing and matching platform.

## Product

MediCrew connects verified doctors and nurses with approved medical transport companies and healthcare organizations for transport missions.

## Development stack

- React Native + Expo
- Supabase Auth / PostgreSQL / Realtime / Edge Functions
- Stripe-hosted invoices for MediCrew service fees
- GitHub

## Data scope

MediCrew does not store patient medical records. The platform stores professional, company, mission, skills, availability, verification, operational and transaction data.
